# Frontend

The browser and desktop shells render the same React application from
`packages/app`.

## Structure

```
packages/app/src/
  routes/                 TanStack Router route components
  features/               feature-owned components, queries and mutations
  components/shell/       sidebar and header
  query/                  API client and query provider wiring
  i18n/                   typed English/Spanish catalogue
  platform/               web/desktop capability contract
  providers.tsx           shared provider composition
  app-root.tsx            application frame
  mount.tsx               entry point used by both shells
```

`apps/web` and `apps/desktop` only mount the shared app and declare their target.

## State

- **Server state** belongs to TanStack Query.
- **Local UI state** belongs to component state or a small Zustand store.
- There is no global API-data store.
- Query keys are feature-specific and exported from the owning feature.

## Routes

| Route        | State                               |
| ------------ | ----------------------------------- |
| `/`          | Redirects to `/dashboard`           |
| `/dashboard` | Static foundation summary           |
| `/inventory` | Inventory placeholder               |
| `/settings`  | Organization identity and save form |

The route tree is generated by the TanStack Router Vite plugin. Do not edit
`routeTree.gen.ts` by hand.

## Shell

- Sidebar: Dashboard, Inventory and Settings.
- Header: signed-in user, theme toggle, language switch and sign out.
- The application frame renders once in the root route.
- Session storage keys and event names use the `inventory-u3` prefix.

## Forms

React Hook Form owns form state and Zod resolvers enforce the same schemas the API
uses. Components do not contain business rules; they render and submit.

## Styling

Tailwind CSS v4 plus design tokens in `packages/ui`. Feature components use the
shared primitives before adding new ones.
